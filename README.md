# Динозавр учится на пикселях: DQN

В папке [rl](rl) — обучение с подкреплением по картинке. Здесь сеть не получает ни расстояний, ни скоростей. Она видит только экран игры, уменьшенный до 150×40, и сама учится, когда держать пробел или «вниз».

- **Среда** ([rl/dino_env.js](rl/dino_env.js), [rl/game.js](rl/game.js)). Настоящая игра из [t-rex-runner](t-rex-runner) (открытая копия из Chromium, wayou/t-rex-runner, лицензия BSD) крутится в Node без браузера, холст даёт `@napi-rs/canvas`. Одно решение сети — 2 кадра игры (30 решений в секунду). Действия — какая клавиша зажата: ничего, пробел, вниз. Всё как с клавиатуры: отпустил пробел раньше — прыжок ниже, «вниз» в воздухе — быстрое падение.
- **Наблюдение**: 4 последних кадра 150×40 в оттенках серого. По их разнице видна скорость. Кадр рисуется 1:1 и уменьшается усреднением блоков 4×4 нашим кодом, а не сглаживанием холста: так картинка в Node и в браузере совпадает побайтно.
- **Награда**: +0.1 за каждый шаг, −1 за столкновение.
- **Сеть** ([rl/model.py](rl/model.py)): 3 свёрточных слоя и две головы — ценность состояния и преимущество каждого действия (dueling).
- **Обучение** ([rl/train.py](rl/train.py)): Double DQN, 3-шаговые возвраты, буфер на 400 тыс. переходов прямо в видеопамяти, 32 партии параллельно в 8 процессах Node. ε-жадное исследование: ε падает с 1 до 0.01 за первые 500 тыс. шагов. Пока Node двигает партии, видеокарта учит сеть. Каждые 200 тыс. шагов — проверка на 8 новых трассах без случайных действий, лучшая сеть сохраняется в `rl/runs/<имя>/best.pt`.

## Как запустить

Один раз поставить зависимости (PyTorch с CUDA и холст для Node):

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install torch numpy --index-url https://download.pytorch.org/whl/cu130 --extra-index-url https://pypi.org/simple
cd rl; npm install; cd ..
```

Обучить, проверить и выгрузить веса для браузера:

```powershell
.venv\Scripts\python rl\train.py --name run1
.venv\Scripts\python rl\play.py rl\runs\run1\best.pt --episodes 16
.venv\Scripts\python rl\export.py rl\runs\run1\best.pt
```

Посмотреть, как играет сеть: запустить веб-сервер из корня проекта

```powershell
python -m http.server 8765 --directory C:\Projects\dino
```

и открыть http://localhost:8765/rl/web/. Под игрой — схема «мозга» ([rl/web/brain.js](rl/web/brain.js)): 4 кадра, которые получает сеть, карты признаков всех трёх свёрток, оба слоя по 256 нейронов, самые сильные вклады нейронов в выходы и оценка каждого действия, всё на текущем ходу. Сеть в браузере считается на TensorFlow.js по тем же весам.

## Проверка

Обучение на 3 млн шагов среды (около 3700 забегов) заняло 22 минуты на RTX 5070 Laptop. Проверка каждые 200 тыс. шагов — 8 новых трасс, предел 5000 очков:

| Шагов | 200 тыс. | 600 тыс. | 1 млн | 1,6 млн | 2 млн | 2,2 млн | 2,4–3 млн |
|---|---|---|---|---|---|---|---|
| Среднее | 541 | 687 | 3202 | 5000 | 3924 | 2205 | 5000 на всех четырёх проверках |

Для сравнения: случайные нажатия дают около 45 очков. Результат по ходу обучения скачет — это обычное поведение DQN, поэтому проверку стоит повторять на последней сети.

Итоговую сеть (3 млн шагов) запускал на 16 новых трассах с пределом 50 000 очков: все 16 забегов дошли до предела, ни одного столкновения. Сеть с 1,6 млн шагов на тех же условиях: от 1371 до 50 000, в среднем 16 489. Поэтому при равных результатах проверки `best.pt` теперь заменяется более поздней сетью.

В браузере та же сеть на TensorFlow.js (WebGL) тратит около 5 мс на ход. Её ответы совпадают с PyTorch до шестого знака, а кадры, которые она получает, — с кадрами при обучении побайтно.
