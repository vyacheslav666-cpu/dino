# Динозавры учатся сами: NEAT

В папке [neat](neat) никакой заранее написанной физики. Динозаврами управляют нейросети, и они учатся методом NEAT, то есть эволюцией.

- В каждом поколении бегут 150 динозавров по одной трассе. У каждого своя сеть.
- Сеть видит: расстояние до препятствия, его ширину, высоту и подъём над землёй, скорость игры, свою высоту и скорость, зазор до следующего препятствия. Выходы: «прыжок» и «пригнуться» (в воздухе это ускоряет падение).
- Каждое поколение проходит 3 разные трассы подряд, оценка сети — среднее расстояние по ним. Так случайно удачная трасса не делает сеть чемпионом. Трасса обрывается на 20 000 очков, чтобы эволюция не стояла. Оба числа меняются на странице.
- Кто пробежал дальше, тот оставляет потомство. Потомки получают изменённые веса, новые связи и новые нейроны. Похожие сети объединяются в виды, чтобы новая структура не вымирала сразу.

Игра — открытая копия из Chromium в папке [t-rex-runner](t-rex-runner) (wayou/t-rex-runner, лицензия BSD). Тренер берёт из неё настоящие классы игры (динозавр, препятствия, столкновения), сам файл игры не меняется.

## Как запустить

Нужен любой локальный веб-сервер из корня проекта, например:

```powershell
python -m http.server 8765 --directory C:\Projects\dino
```

Потом откройте http://localhost:8765/neat/ и нажмите «Макс». Примерно за 60 поколений (около двух минут) лучший динозавр проходит все три трассы до 20 000 очков. Кнопка «Показать лучшего» запускает лучшую сеть без предела очков.

## Проверка

Лучшую сеть запускал на новых трассах без предела очков.

| Как учили | Забеги лучшего на новых трассах |
|---|---|
| 1 трасса на поколение, предел 5000, 56 поколений | 10 забегов, от 471 до 62 427 очков, три из них меньше 2000 |
| 3 трассы на поколение, предел 20 000, 62 поколения | 5 забегов, ни одного проигрыша: один дошёл до 715 694 очков, остальные остановлены на 113 000–116 000 |
